## JSONL input contract
Each line is one immutable, pregame, binary single-market prediction. Tests/test_core.py contains explicitly synthetic fixtures, never performance evidence. Use these required fields:

| Fields | Meaning |
|---|---|
| event_id, sport, season | Canonical league event ID and verified season |
| market, player_id, side, line, period, rules_id | Exact stat/selection/threshold and versioned settlement policy; player_id is empty for team markets |
| book, source_url, provider_id, source_verified | Exact sportsbook, provenance, independence lineage, completed source verification |
| decision_at, start_at, quote_at, retrieved_at | Timezone-bearing ISO timestamps; pregame only |
| model_version, model_fit_at, p | Frozen historical model and probability available at decision |
| features | Nonempty list of {source_url, available_at}; archive original versions of injuries, lineups, odds and every input |
| outcome, settled_at | win/loss/push/void and actual settlement availability time |
| odds | Decimal total return including stake |
| p_lower, p_upper, uncertainty_method | Independently validated probability interval, with method/version; absence forces PASS |
| available, valid_until, limit | Execution availability, verified quote lifetime, maximum monetary stake |
| rules_verified, independent_reference_verified | Completed settlement and independent comparison checks |

Optional: opposing_odds plus opposing_market_verified (same line/time/rules, opposite side); fee (absolute fee per executed wager); close (full identity, book, odds, quote_at, source_verified, last_prestart_verified).
Input flags are assertions requiring adapter-level evidence; they are not automatic source verification. No trusted external feed adapter is installed. Preserve rejected records separately; fail-fast invalid rows stop the run rather than silently biasing the cohort. Audit missing price/feature/close rates before exporting accepted rows.

## Evaluation protocol
1. Archive baseline code, data checksum, cutoffs, eligibility rules, sample-size/power targets, metric priorities and experiment count before candidate work. Score unchanged probabilities first. Train constant and bin-calibration baselines using training labels only. Use validation Brier to select raw or training-bin-calibrated probabilities; no threshold or profit tuning.
2. Freeze model/selection before held-out access. Compare Brier and log loss against raw, constant, coinflip and proportional de-vigged market (matched subset). Reliability bins show n, predicted probability, and observed frequency; Brier alone does not isolate calibration. Sparse calibration bins are unstable. Optional future calibration slope/intercept and reliability plots need enough data.
3. Report paired event bootstrap Brier differences; negative favors candidate. Subgroup results are exploratory, not independent discoveries. Inspect log-loss regressions, week/season block sensitivity, temporal drift, and multiple experiments before promotion. No automatic promotion, even if an interval excludes zero. Establish power from event counts and a prespecified practically useful change, not winning-bet counts.
4. Singles stake is at most one monetary unit or book limit. A quote must remain verified for five seconds after decision; otherwise skip, never substitute a later quote retrospectively. Fees reduce P&L. Pushes/voids return stake; gross attempted stake remains ROI denominator. Outcome corrections require rule-specific archived settlement records. No partial fills, exchange commission, taxes, bankroll depletion, multi-book correlated exposure or exotic settlement engine: return estimates need those additions where applicable.
5. Price CLV = decision decimal odds / closing decimal odds - 1, same sportsbook/event/side/exact line/period/rules, closing quote verified as last before start. Report n and missing coverage. This is price improvement, not de-vigged probability CLV. Different lines are not converted; retain line movement separately in append-only quote records.
6. Calibrated candidates discard raw uncertainty intervals and abstain from execution until candidate uncertainty is independently established. Bootstrap metric intervals are not per-bet probability intervals. Same-game parlays, live markets, flex payouts and automatic betting remain unsupported.
